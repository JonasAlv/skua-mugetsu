**The game player bundled with [BonxieMux](https://github.com/JonasAlv/BonxieMux).** BonxieMux downloads this release automatically; you don't need to install it separately.

## Skua build 1.6.0-skua.5 (Linux — Wayland & X11)
- Unified Linux build supporting both **Wayland** (`Skua.WaylandHost` DMA-BUF) and **X11 / XWayland** (`Skua.X11Host` XComposite + DRI3 DMA-BUF).
- Forwarded input, focus, visibility, and resize over the Skua bridge (`SkuaInput`), with `SKUA_EMBEDDED=1` hiding standalone fullscreen/restart controls.
- x86-64-v2 build included for Linux processors without AVX2.

Mugetsu 1.6.0 plus `source/patches/skua.patch`:
- `--skua-bridge host:port`: connects to BonxieMux to bridge `ExternalInterface` calls/events and forwarded `SkuaInput` events. The player exits when BonxieMux closes the connection.
- `SKUA_EMBEDDED=1`: marks the player as embedded inside BonxieMux (no update check, no fullscreen toggle, safe menu behavior).

Without those options it behaves like Mugetsu 1.6.0.
