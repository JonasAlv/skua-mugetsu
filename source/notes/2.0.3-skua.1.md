**The Linux game player bundled with [BonxieMux](https://github.com/JonasAlv/BonxieMux).** BonxieMux downloads this release automatically during build; you don't need to install it separately.

## Skua build 2.0.3-skua.1

Mugetsu 2.0.3 (upgraded from 1.6.0, including Performance mode, memory limit and unused gear cleanup with Free memory now, frame pacing and FPS limit, frame interpolation fixes, colour-custom, `/spellcraft` ink and rune glow fixes, 1440p/4K room tint fixes, broader 64-bit processor support, and Ruffle 2026-11-10) plus `source/patches/skua.patch`:

- `--skua-bridge 127.0.0.1:port` — loopback-only TCP bridge for `ExternalInterface` calls, game events, and live `mugetsu_setting` updates from BonxieMux's Options → Applications
- `SKUA_EMBEDDED=1` — enables embedded mode on Linux (where BonxieMux handles X11/Wayland embedding), disabling standalone update checks and resize-on-metadata
- Runtime `VERSION` set to `2.0.3-skua.1`
- Exits cleanly when the bridge connection closes or the embedded surface is lost
- AVM2 `JSON.stringify` fixes for AQW (`Event` getters omitted, whole numbers `< 9e15` serialized without `.0`)

Without those options it behaves like Mugetsu 2.0.3.
